# Vendor bills

1. Resolve the vendor by name. If several vendors match, list them with enough detail to tell them apart and let the user choose. Never guess between similar names.
2. List the vendor's open bills with amount, due date, and status.
3. Give the total owed to this vendor and flag anything past due.
4. Note any bill with a partial payment against it, showing applied and remaining amounts.
5. Offer the vendor's recent payment history if the user is deciding what to pay next.
